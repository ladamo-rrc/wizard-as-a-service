# Wizard as a Service

![Wizard as a Service Logo](public/images/wizards/wizard-as-a-service-logo.png)

Wizard as a service is a fun fantasy API where a collection of wizards will read you a random prophecy, as well as give you a random excuse for when you need to get out of plans or call out of work!

Lilly Adamo

### Current Features

- Prophecy readings
- Excuses
